# Activity Finder

## Configuration

Copy `.env.example` to `.env` and set the Foursquare and Firebase values before
running `node server.js`. For deployment, configure the same variables in the
hosting provider's environment settings. Firebase client configuration is
served by `/api/firebase-config` rather than stored in the browser source.

Firebase web API keys are identifiers, not authorization secrets: the browser
must receive this configuration to use Firebase. Restrict the key in Google
Cloud and secure Firebase data with Authentication and database rules.
